# 数据字典（Schema 说明）

## 数据来源

Tableau 官方「Sample - Superstore」示例数据集（`https://public.tableau.com/app/sample-data/sample_-_superstore.xls`），含三张工作表。

## 表结构（多表关联）

| 表 | 角色 | 主键 | 关联字段 |
|---|---|---|---|
| Orders（订单事实表） | 事实表 | Row ID / Order ID | Region→People，Order ID→Returns |
| People（区域经理维度表） | 维度表 | Region | Region |
| Returns（退货表） | 维度表 | Order ID | Order ID |
