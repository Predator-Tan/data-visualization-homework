# 《Excel数据可视化——从图表到数据大屏》Python 迁移

> 对应课程：《大数据分析及数据可视化》
> 任务：将《Excel数据可视化——从图表到数据大屏》（清华·郭宏远）的内容迁移成 Python 实现，并上传 GitHub/Gitee。

本目录将书中的 Excel 图表模板、动态图表、数据大屏，用 Python（matplotlib + plotly）逐一复现，**数据全部来自教材配套的 xlsx/xlsm 文件**（已复制到 `data/` 目录）。
